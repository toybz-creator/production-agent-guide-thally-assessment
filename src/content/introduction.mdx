Production Agent Guide gives an AI coding agent a repeatable way to understand a software project, plan work, implement it, evaluate the result, and leave useful project knowledge behind.

It is for developers and teams who use coding agents in an existing codebase and want their work to reflect project decisions, engineering standards, and verifiable evidence from one task to the next.

## What you get

- A reusable instruction library with numbered `PAG-*` rules for production-focused engineering.
- A six-stage workflow: Rewrite, Planning, Implementation, Evaluation, Feedback, and Iteration.
- A project-specific `harness/` folder for decisions, product context, architecture, task records, and operating guidance.
- A CLI that installs missing harness files and checks whether the package and harness are present.

The package is the shared baseline. The files in your project’s `harness/` folder hold the context that should survive package upgrades. Customize the harness for your product instead of editing files inside `node_modules/production-agent-guide/`.

## How a task moves through the guide

<Mermaid>{`
flowchart LR
  A[Rewrite the request] --> B[Plan the work]
  B --> C[Implement]
  C --> D[Evaluate with evidence]
  D --> E[Give feedback]
  E --> F[Iterate and update project memory]
`}</Mermaid>

Use the [quickstart](/task-1/quickstart) to install and activate the package. Then follow the [harness customization guide](/task-1/practical-guide) to record project-specific decisions.
